### 4.3 `src/ExecutorImpl.cpp` 的 `Execute`

```cpp
for (const auto cmd : commands)
{
    std::unique_ptr<ICommand> cmder;

    if (cmd == 'M')      { cmder = std::make_unique<MoveCommand>(); }
    else if (cmd == 'L') { cmder = std::make_unique<TurnLeftCommand>(); }
    else if (cmd == 'R') { cmder = std::make_unique<TurnRightCommand>(); }
    else if (cmd == 'F') { cmder = std::make_unique<FastCommand>(); }

    if (cmder)
    {
        cmder->DoOperate(*this);
    }
}
```

- 循环内**没有任何方向判断**（`pose.heading` 只出现在 `Move`/`TurnLeft`/`TurnRight` 内部）；
- 每种指令只做“创建命令对象”，执行收敛为唯一一句多态调用 `cmder->DoOperate(*this);`；
- 圈复杂度由“指令 × 方向”的多层分支降为“四条单层分支 + 一次统一调用”。
